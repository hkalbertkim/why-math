# Teaching visual sources

## First raster composition — zero and counting

- **Basket (3D PNG):** `public/assets/basket.png`, original at [microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji/blob/main/assets/Basket/3D/basket_3d.png).
- **Red apple (3D transparent PNG):** `public/assets/red-apple.png`, original at [microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji/blob/main/assets/Red%20apple/3D/red_apple_3d.png).
- **License:** Microsoft Fluent Emoji, **MIT**, copyright Microsoft Corporation. Full license: [LICENSE-fluentui-emoji.txt](../public/assets/LICENSE-fluentui-emoji.txt).
- **Raster background:** `public/assets/counting-bg.png`, generated for Why Math? with Pillow in the 2026-11-09 hackathon build; no external source.

The interactive teaching scene is CSS composition of a raster background and small transparent PNG sprites. Numbers, buttons, explanatory text, and math remain separate accessible HTML to support multilingual display and dynamic learner interaction.

Image design is a first-pass demo treatment, not an illustration quality benchmark or proof of learning gains. Use human review before broad production deployment.
