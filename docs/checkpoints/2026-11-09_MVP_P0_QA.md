# Why Math? — MVP P0 / QA checkpoint

**Date:** 2026-11-09 KST. **Host:** MSM2-1. **Stage:** Post-P0 hardening, pending full release approval.

## Changes made

- Replaced public session-list endpoint with private session capabilities (256-bit tokens, SHA-256 digest persisted, constant-time digest compare). Read, turn, and simulate endpoints check access. Sensitive hash excluded from API responses. Pre-token legacy sessions have no capability and cannot be accessed over API.
- Replaced direct JSON writes with in-process queue, temporary file + flush + atomic rename + parent-directory fsync. Invalid/corrupt session storage no longer silently resets. Serialized parallel turns for each session.
- Separated ordinary human learning entry from explicit test-fixture mode. Three AI personas are test fixtures, not age-based teaching engines; replay mode gated to fixture sessions.
- Guided concept intro now corresponds to selected topic (zero, number line, or negative numbers).
- Fixed React useEffect callback accidentally returning a value. Browser no longer crashes after a lesson turn.
- Guarded simple integer-comparison errors and demoted user questions / uncertainty to observation rather than a proven misconception. This is not general mathematical proof verification.

## Remaining limitations / release gates

1. gStack independent code review returned **PASS FOR SCOPED P0** for prior blocking defects. This is not educational-model approval or production readiness. Evidence: `/tmp/why-math-gstack-p0-final.md`.
2. One-process JSON persistence does not protect against multiple application worker processes. Do not run concurrent workers against one data file. Database needed for real deployment.
3. Learner mastery logic remains heuristic; simulated learners do not validate human learning benefit.
4. Free exploration is currently limited by the tiny concept map. The current UI promises more than the teaching engine can guarantee.
5. Authentic, reviewed PNG/transparent PNG/GIF math teaching assets not yet integrated; HTML/CSS number line currently the only interactive visual example.
6. No public deployment QA, recording or submitted 90-second English demonstration; the backend must not be exposed publicly without account/rate-limit/security review.
